# 内容资讯模块 页面操作测试清单

> 适用版本：`889dd4e`（补齐后台政策/资讯管理之后）
> 全程只点页面，不用接口工具、不用脚本。
> 一条主链路约 10 分钟，政策 + 资讯全部走完约 25 分钟。

---

## 0. 测试前准备

### 0.1 三个地址

| 端 | 地址 | 用途 |
|---|---|---|
| 管理端 | http://localhost:3000 | 录入、编辑、发布、下架、删除 |
| 门户 | http://localhost:3100 | 验证前台是否可见 |
| 后端 | http://localhost:8080 | 不用直接访问，保证它在跑即可 |

### 0.2 两个账号

| 账号 | 密码 | 角色 | 本次用途 |
|---|---|---|---|
| `admin` | `201391` | 管理员 | 正常流程，拥有 `cms:*` 全部权限 |
| `farmer01` | `201391` | 农户 | 反例，验证"没有权限就看不到入口" |

### 0.3 两个必须做的动作（不做会白测）

1. **重启后端**。`cms:*` 权限点和两个菜单是启动时写进库的，不重启就没有「政策管理」「资讯管理」。
2. **管理端退出后重新登录**。菜单和按钮权限在登录时装配，旧会话仍是老快照。

### 0.4 开两个浏览器窗口

- 窗口 A：管理端（Chrome 普通窗口），登 `admin`
- 窗口 B：门户（Chrome 无痕窗口，**不登录**，当游客）

> 用无痕是为了避免门户读到管理端的登录态，也方便随时关掉重开验证"是否真的对游客可见"。

### 0.5 一个准备丢弃的标题

后面每一步都用同一个标题串起来，建议直接用：

- 政策：`钟山镇2027年产业帮扶项目申报指南（页面测试）`
- 资讯：`钟山镇首届农耕文化节下月开幕（页面测试）`

带「（页面测试）」是为了搜索时能精准命中，也方便测完删干净。

| 1.4 | 点「资讯管理」 | 筛选多一个「栏目」下拉；表格多一列「关联地点」 |

**反例（同一关一起测）**

| 步骤 | 操作 | 应该看到 |
|---|---|---|
| 1.5 | 窗口 A 退出，改用 `farmer01` / `201391` 登录 | 左侧**没有**「政策管理」「资讯管理」，甚至「系统管理」整组都不出现 |

## 2. 政策主链路（10 分钟，一条线走完）

### 2.1 新建 → 必须先是草稿

| 步骤 | 操作 | 应该看到 |
|---|---|---|
| 2.1.1 | 政策管理 → 点「新增政策」 | 弹出居中对话框，字段：政策标题、政策文号、发布单位、封面地址、摘要、政策正文 |
| 2.1.2 | 标题填 `钟山镇2027年产业帮扶项目申报指南（页面测试）`；文号 `钟政发〔2026〕88号`；发布单位 `钟山镇人民政府`；摘要随便一句；正文写两行（见下） | 正文分两行写，第二行开头空一行也行，用来验证分段 |
| 2.1.3 | 点「确定」 | 右上角绿色提示 **「已保存为草稿，点「发布」后前台可见」**；对话框关闭；表格第一行出现这条记录，状态是灰色 **草稿** 标签 |

正文建议这样填（验证分段用）：

```
第一条 申报对象为钟山镇域内从事种养殖的脱贫户与监测户。

第二条 单个项目补助不超过 5 万元，申报截止 2026 年 12 月 31 日。
```

### 2.2 草稿在前台必须看不见

| 步骤 | 操作 | 应该看到 |
|---|---|---|
| 2.2.1 | 切到窗口 B（游客），打开 http://localhost:3100 | 首页正常 |
| 2.2.2 | 滚到「扶贫政策」区块，看左上「最新发布」大图的标题 | 仍是原来那篇，**不是**刚建的「（页面测试）」；右侧「共 N 条最新政策」也没变化（首页取最新 5 条，数字仅作参考，判据以大图标题为准） |
| 2.2.3 | 点该区块右上「查看全部」→ 进入政策专栏 | 列表里**找不到**「（页面测试）」这条 |
| 2.2.4 | 在「关键词」框输入 `产业帮扶项目` → 点「查询」 | 显示「暂无符合条件的政策」 |

> 这一步是草稿态的核心证据。**如果草稿在前台能搜到，直接判不通过。**

### 2.3 发布 → 前台立刻可见

| 步骤 | 操作 | 应该看到 |
|---|---|---|
| 2.3.1 | 回窗口 A，找到这条草稿，点操作列「发布」 | 绿色提示 **「发布成功，门户政策列表已可查看」**，状态变绿色 **已发布**，发布时间出现具体时间 |
| 2.3.2 | 窗口 B 刷新政策专栏页面（F5） | 列表出现这条，左侧有文号标签「钟政发〔2026〕88号」，摘要、发布单位、浏览量 0 |
| 2.3.3 | 窗口 B 回首页刷新 | 「扶贫政策」区块里，这篇成为左上大图的 **最新发布**；区块右侧「共 N 条最新政策」通常仍是 5（首页只取最新 5 条，满了就把最旧的一条挤出去，数字不变属正常，判据看内容不看数字） |

> 发布没有二次确认弹窗，点了就生效，这是设计如此，不是漏了确认。

### 2.4 详情页与浏览量

| 步骤 | 操作 | 应该看到 |
|---|---|---|
| 2.4.1 | 窗口 B 在政策列表点这条的标题 | 进入详情：顶部文号、发布单位、发布时间、浏览量；正文**分成两段**显示（不是一整坨） |
| 2.4.2 | 记下浏览量数字，按 F5 刷新一次 | 浏览量 +1（每刷一次都加，没有去重，属已知口径） |
| 2.4.3 | 看详情页底部 | 有一句「本政策由 钟山镇人民政府 发布，如有疑问请咨询镇便民服务中心。」 |

### 2.5 编辑 → 保持已发布，改动即时生效

| 步骤 | 操作 | 应该看到 |
|---|---|---|
| 2.5.1 | 窗口 A 点这条的「编辑」 | 对话框打开，**六个字段都回显了刚才填的值**（这是编辑回显是否正常的判据） |
| 2.5.2 | 标题末尾加「（已修订）」；发布单位改成 `钟山镇乡村振兴办`；正文改成一段话；点「确定」 | 提示 **「修改成功」**；表格里标题、发布单位立刻变，**状态仍是「已发布」** |
| 2.5.3 | 窗口 B 刷新列表和详情 | 看到的是改后的标题与单位（不需要重新发布） |
| 2.5.4 | 窗口 A 把标题改回原样 | —— |

> 编辑不会把已发布打回草稿，这是刻意设计：改错别字不用重新走一遍发布。

### 2.6 下架 → 前台立刻消失

| 步骤 | 操作 | 应该看到 |
|---|---|---|
| 2.6.1 | 窗口 A 点这条的「下架」 | 弹确认框 **「下架后门户将立即看不到这条政策，确认下架？」** |
| 2.6.2 | 点「取消」 | 提示「已取消」，状态不变（先验证取消是有效的） |
| 2.6.3 | 再点「下架」→ 点「确定」 | 提示 **「已下架」**，状态变黄色 **已下架** |
| 2.6.4 | 窗口 B 刷新政策专栏 | 列表里没有了；「共 N 条」回到发布前的数字 |
| 2.6.5 | 窗口 B 直接在地址栏打开该详情页（或用浏览器后退再刷新） | 显示「政策不存在或已下架」，不是白屏也不是 500 |

### 2.7 重新上架 → 发布时间不变（易被误判为 bug）

| 步骤 | 操作 | 应该看到 |
|---|---|---|
| 2.7.1 | 窗口 A 对这条点「发布」 | 状态回到 **已发布**，前台又能看到 |
| 2.7.2 | 对比现在的「发布时间」和 2.3.1 时的发布时间 | **完全一样，没有变成刚才的时间** |
| 2.7.3 | 窗口 B 首页看「最新发布」大图 | 仍是原来那篇，这篇不会因为重新上架跳到首位 |

> 这是刻意保留首次发布时间，避免下架再上架把旧内容顶到首页。**答辩时被问"为什么时间没更新"，就答这个。**

### 2.8 删除 → 后台也查不到

| 步骤 | 操作 | 应该看到 |
|---|---|---|
| 2.8.1 | 窗口 A 点这条的「删除」 | 弹确认框「确认删除已选中的数据项吗？」 |
| 2.8.2 | 点「确定」 | 提示 **「删除成功」**，表格里这条消失 |
| 2.8.3 | 在「标题/文号」里输入 `页面测试` 点「搜索」 | 命中 0 条 |
| 2.8.4 | 切到「发布状态 = 全部」再搜一次 | 仍然 0 条（逻辑删除，任何状态都查不到） |

## 3. 资讯主链路（8 分钟）

结构与政策完全对称，只测**不一样的地方**，剩下的照第 2 节走一遍即可。

### 3.1 必须多测的三点

| 关注点 | 操作 | 应该看到 |
|---|---|---|
| **栏目是必填** | 资讯管理 → 新增 → 只填标题和正文，不动「资讯栏目」→ 点「确定」 | 栏目下拉框下方红字 **「请选择资讯栏目」**，对话框不关 |

| **栏目筛选真的在过滤** | 窗口 B 依次点 chip：全部 / 景点宣传 / 旅游推介 / 乡镇历史 / 地域文化 / 人文地理 | 只有「全部」和「地域文化」两个视图里有这条；其余四个视图「暂无符合条件的资讯」 |

### 3.2 资讯侧的两个特有校验

| 操作 | 应该看到 |
|---|---|
| 窗口 B 资讯搜索框输入 `农耕文化节` | 能命中（关键词同时匹配标题和摘要） |
| 窗口 B 点进详情 | 顶部有栏目标签「地域文化」、地点「湖亭村」、发布时间、浏览量；正文按两段显示 |

### 3.3 批量删除（政策侧没测的那条）

| 步骤 | 操作 | 应该看到 |
|---|---|---|
| 3.3.1 | 窗口 A 连续新建两条资讯，标题分别带 `批量删除1`、`批量删除2`（只填标题/栏目/正文即可） | 两条都是草稿 |
| 3.3.2 | 勾选这两行左侧复选框 | 顶部「删除」按钮由灰变可点 |
| 3.3.3 | 点「删除」→ 确定 | 提示「删除成功」，两条一起消失 |

## 5. 判定表：什么算测过

每一关按下面四条同时成立才算通过，缺一条就记问题。

| 维度 | 判据 |
|---|---|
| **状态流转** | 草稿(灰) → 已发布(绿) → 已下架(黄) → 已发布(绿)；按钮随状态在「发布/下架」之间切换，不会两个同时出现 |
| **前台可见性** | 草稿和下架：列表搜不到、详情提示「不存在或已下架」；已发布：列表能搜到、首页区块里能见到（首页只展示最新 5 条政策 / 8 条资讯，满了会挤掉最旧的）、详情能打开 |
| **字段一致性** | 后台填的标题/文号/单位/栏目/地点，前台一字不差；编辑后前台刷新即变，无需重新发布 |
| **计数与副作用** | 每次打开详情浏览量 +1；下架再上架发布时间不变；删除后任何状态都搜不到 |

### 明显不通过的现象（见到就记 bug）

- 新增后不用点发布，前台就能看到 → 草稿态失效
- 点了发布，前台刷新仍看不到 → 发布没写库或前台过滤条件错
- 下架后详情页报 500 或白屏 → 异常没兜住
- 编辑后状态被打回草稿 → 编辑逻辑误改状态
- 删除后换「全部」状态还能看到 → 逻辑删除没生效
- 农户账号能看到「政策管理」菜单 → 权限点没生效

## 6. 答辩演示版（5 分钟，只演一条）

时间紧就只演政策这一条，顺序不能乱：

1. 管理端「政策管理」→ 新增，标题写 `关于2027年产业帮扶项目申报的通知`，正文两段 → 确定（**强调：现在是草稿，前台看不到**）
2. 切门户政策专栏，搜关键词 → 空（**这一步是加分项，证明有发布审核概念**）
3. 回管理端点「发布」→ 提示发布成功
4. 切门户刷新 → 出现了；点进详情 → 两段正文、文号、浏览量
5. 回管理端点「下架」→ 门户刷新 → 消失
6. 最后点「删除」把演示数据清掉，收尾干净

一句话总结口径：**录入即草稿，发布才上架，下架即下线，删除只标记。**

## 7. 常见"看着像 bug 其实不是"

| 现象 | 原因 |
|---|---|
| 草稿的「发布时间」是空的 | 发布时间在首次发布时才写入，草稿没有 |
| 下架再上架，时间还是老的，首页也不冒头 | 刻意保留首次发布时间，防止旧内容被顶到首页 |
| 同一条详情刷新两次，浏览量 +2 | 浏览量不做去重，按访问次数累计 |
| 正文里的 HTML 标签原样显示 | 正文是纯文本，门户按换行分段 |
| 删除后数据库里还有这条 | 逻辑删除（`deleted=1`），后台和前台都查不到，但数据可追溯 |
| 门户页面要手动 F5 才看到变化 | 前端不做轮询，列表在进入页面时拉一次 |
| 点「发布」没有二次确认 | 只有「下架」和「删除」有确认框，发布是即时动作 |
