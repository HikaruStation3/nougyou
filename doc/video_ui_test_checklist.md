# 短视频模块手工测试流程（系统操作版 · FR-011 / 012 / 020 / 021 / 035）

> 全程只点页面，不写代码、不调接口。每一步都写了「点哪里」和「该看到什么」。
> 顺序：游客只读 → 买家互动 → 商家发布 → 管理员审核 → 越权边界，约 40 分钟。
> 测试会真实写库（点赞、评论、关注、发布、审核），第 8 节写了怎么收尾。

## 2. 第一轮：游客只读（不登录，5 分钟）

### 2.1 入口与首屏

1. 打开 http://localhost:3100 → 顶部导航点「助农短视频」。
   - **该看到**：地址变 `#/videos`；全屏黑底；第一条自动播放；左上返回箭头；顶部中间「推荐 / 最热」；右侧竖排 5 个图标（头像、心、气泡、纸飞机、店铺）；底部 `@云岭茶庄` + 标题 + 简介 + `N 次播放 · 时间`。
2. 记下第一条标题：应为「村里的老屋和晒谷场」。
3. 看右上角：**没有「发布」按钮**（只有商家账号才显示）。

### 2.2 播放控制

4. 点一下视频画面 → 暂停，中央出现大播放按钮。
5. 再点大按钮 → 继续播放。
6. 鼠标移到最底部细进度条，在中间点一下 → 进度跳到一半左右继续播。

### 2.3 上下切换

7. 鼠标滚轮向下滚一格 → 切到下一条（「蔡伯的地瓜干…」）并自动播放，上一条暂停。
8. 点右侧「下一个」箭头（或按键盘 `↓`）→ 下一条。
9. 按 `↑` → 上一条。
10. 按 `空格` → 暂停 / 播放；按 `M` → 静音 / 取消静音。

### 2.4 声音

11. 点右上角喇叭图标 → 图标在「有声 / 静音」之间切换。
12. 刷新页面（F5）→ 声音状态保持上一次的选择（存在浏览器本地）。
13. 如果首次进入被浏览器拦了带声播放：右上会出现 **「点击开启声音」** 小气泡（8 秒消失）。点它，或点页面任意位置，声音恢复。

### 2.5 排序

14. 点顶部「最热」→ 列表重载，第一条变「兴化米粉手工制作全过程」。
    - 顺序应为：米粉(128) → 九鲤湖(96) → 地瓜干(65) → 老屋(12)。
15. 点「推荐」→ 回到按发布时间倒序：老屋 → 地瓜干 → 九鲤湖 → 米粉。

### 2.6 播放量与会话去重

16. 停在第一条，记下底部「N 次播放」。
17. 滑到下一条，再滑回来 → 数字**不变**（同一页面会话内同一视频只记一次）。
18. 刷新页面后再播这条 → 数字 **+1**。

### 2.7 分享与深链

19. 点纸飞机图标 → 提示「链接已复制，去分享给朋友吧」。
20. 新开标签页粘贴 → 打开后直接定位到这条视频（地址形如 `#/videos?id=6`）。

### 2.8 游客边界

21. 点右侧心形 → 提示「登录后才能点赞、评论和关注」，自动跳登录页，地址带 `?redirect=/videos`。
22. 用 buyer01 登录 → 自动回到短视频页（不用手动再点导航）。
23. 点头像 → 退出登录，回到短视频页，点「评论」气泡 → 面板能打开、能看到评论（游客可以看评论）。
24. 在输入框打字后点「发送」→ 跳登录页（草稿会丢，属预期）。
25. 滑到最后一条再往下 → 出现 **「已经看完啦」** 卡片 + 「逛农产品商城」「回首页」两个按钮（点「回首页」能回去，两个都点一次）。

- [ ] 游客冒烟通过

## 3. 第二轮：买家互动（buyer01，10 分钟）

### 3.1 点赞（开关，不是只加不减）

1. buyer01 登录 → 顶部「助农短视频」→「推荐」。
2. 第一条「老屋」：buyer01 之前点过 → 心是**红色实心**，数字 12。
   - 点一下 → 变灰，11。
   - 再点一下 → 变红，12，心有一次跳动动画。
3. 切到「蔡伯的地瓜干」：buyer01 没点过 → 灰心 65。点一下 → 红 66。
4. 刷新页面 → 仍是红心 66（点赞已落库）。
5. 再点回灰 65，把数据还原。

> 数字必须严格 ±1，不能跳 2、不能点了不变。

### 3.2 评论列表与回复归并

6. 到「兴化米粉」这条（128 赞、3 评论）点气泡 → 右侧滑出评论面板，标题 **「3 条评论」**。
7. 面板里应是 2 条一级评论 + 1 条回复：
   - 最上面：**丽丽**「这种手工米粉煮之前要泡多久？」（09-27，最新在上）
   - 下面：**小娟**「看着就香，已经下单两袋了。」，其下缩进一条 **「吴叔山货铺 回复 @小娟：谢谢支持，明天一早就发。」**
8. 面板标题的 3 = 右侧气泡上的 3（总数含回复）——数字对得上就对了。

### 3.3 发评论

9. 输入「手工测试：米粉很香」→ 点「发送」。
   - **该看到**：toast「评论已发布」；新评论出现在最上面；面板标题变 4，右侧气泡也变 4。
10. 输入框自动清空；不输入时「发送」按钮是灰的，点不动。
11. 连续输入超过 200 字 → 到 200 字就输不进去（输入框有 200 字上限）。

### 3.4 回复

12. 在自己刚发的评论下点「回复」→ 输入框上方出现「回复 @小娟 ×」，占位文字变「回复TA…」。
13. 输入「自己回复自己测试」→ 发送。
    - **该看到**：这条回复缩进在自己评论下面，显示「小娟 回复 @小娟：自己回复自己测试」；面板标题 5，气泡 5。
14. 点「×」取消回复 → 输入框回到「说点什么…」。

### 3.5 删除（含级联删除）

15. 在自己那条一级评论上点红色「删除」→ 确认框「删除后不可恢复，确认删除这条评论？」→「删除」。
    - **该看到**：toast「已删除」；自己的一级评论和刚发的回复**一起消失**；面板标题 5 → 3，气泡回到 3。
16. 看别人的评论（丽丽、小娟的）→ **没有「删除」按钮**（只有本人 / 视频作者 / 管理员能删）。

> 这一步同时验证了「删一级评论会连带删回复、计数按实际删除条数回退」。

### 3.6 关注（注意：buyer01 三个商家都已关注）

17. 现状：buyer01 已关注 绿野农场、鲜果合作社、云岭茶庄，所以视频页头像右下角**看不到 + 号**。
18. 点「兴化米粉」右侧「店铺」图标 → 弹出商家主页：
    - **该看到**：店铺名「绿野农场」、`吴叔山货铺 · 钟山镇农户商家`、粉丝 / 在售 / 视频 三个数字，右侧按钮显示 **「已关注」**。
19. 点「已关注」→ toast「已取消关注」，粉丝数 -1，按钮变成蓝底「+ 关注」。
20. 关闭弹窗 → 这条视频头像右下角出现 **+** 角标。
21. 点 **+** → toast「已关注，刷到新视频会优先推荐」，角标消失。
22. 再打开商家主页 → 按钮回到「已关注」，粉丝数恢复。

### 3.7 商家主页的其他入口

23. 点头像 / 点底部 `@店铺名` → 都能打开同一个弹窗。
24. 在「在售农产品」里点一个商品 → 弹窗关闭，跳商品详情页。
25. 在「TA 的短视频」里点另一条视频的封面 → 弹窗关闭，信息流定位到那条视频并播放。
26. 关掉弹窗：右侧操作栏只有 5 个图标（头像、心、气泡、纸飞机、店铺），没有第 6 个。

- [ ] 买家互动通过

## 4. 第三轮：商家发布（farmer02 秀兰农场，10 分钟）

### 4.1 入口

1. farmer02 登录 → 右上头像下拉 →「我的短视频」。
   - **该看到**：标题「我的短视频」；按钮「去刷短视频」「发布短视频」；筛选「全部 / 待审核 / 已通过 / 已驳回」。
2. 当前应有 2 条：九鲤湖（已通过）、山茶油（待审核）。
3. 点「待审核」→ 只剩山茶油；点「已驳回」→ 空态「还没有发布短视频」。

> 另一个入口：短视频页右上角「发布」→ **只是跳到这个页面**，不会直接弹窗，还要再点一次「发布短视频」。

### 4.2 发布视频 A（后面走"通过"路径）

4. 点「发布短视频」→ 弹窗。
5. 点虚线框选视频：`backend/src/main/resources/static/media/video/v1.mp4`。
   - **该看到**：框内出现视频画面、文件名、大小、「时长 0:10」、「重新选择」；下方封面自动出现；封面滑块范围 0~10 秒。
6. 拖动封面滑块到 3 秒 → 封面画面变化。
7. 标题输入「测试视频A-秀兰农场」。
   - 先清空标题再点别处 → 红字「请填写视频标题」。
   - 只输 1 个字 → 红字「标题长度需在 2-50 字之间」。
8. 简介输入「自动化测试用，稍后删除」（≤500 字）。
9. 点「提交审核」→ 出现上传进度条（0→80% 传视频，80→100% 传封面）。
   - **该看到**：toast「已提交，等待平台审核」；弹窗关闭；列表最上面多一条「测试视频A-秀兰农场」，黄色标签「待审核」。

### 4.3 前台不可见（审核的核心意义）

10. 新标签页打开 `http://localhost:3100/#/videos`（游客或 buyer01 都行），按「推荐」看前几条 → **没有**「测试视频A」。
11. 滑到底 → 也没有；尾卡照常出现。
12. 回商家「我的短视频」→ 视频 A 在，标签「待审核」。
    - 结论：待审核内容只有作者本人和管理员看得到。

### 4.4 发布视频 B（后面走"驳回"路径）

13. 再点「发布短视频」，同样传 v1.mp4，标题「测试视频B-待驳回」，简介随意，提交。
14. 列表出现第二条「待审核」。

### 4.5 表单边界

15. 不选视频直接点「提交审核」→ 提示「请先选择视频文件」。
16. 选一个非视频文件（文件选择框右下角把过滤器改成「所有文件」，再选一个 .txt）→ 提示「请选择视频文件」。
17. 选一个超过 100MB 的视频 → 提示「视频不能超过 100MB」（没有就跳过）。
18. 选一个超过 10 分钟的视频 → 选完就提示「平台只接收 10 分钟以内的短视频」，提交也会被拦（没有就跳过）。

## 5. 第四轮：管理员审核（admin，10 分钟）

### 5.1 入口与列表

1. 打开 http://localhost:3000 → admin / 123456 + 验证码。
2. 左侧「系统管理」→「短视频审核」。
   - **该看到**：筛选区（审核状态下拉、关键字、查询、重置）；表格列：视频 / 商家 / 互动数据 / 审核状态 / 展示状态 / 提交时间 / 操作。
3. 默认排序：**待审核在最上面**（山茶油、视频 A、视频 B 三行，按提交时间倒序）。
4. 审核状态选「待审核」→ 查询 → 只剩这三条。
5. 关键字输「秀兰农场」→ 查询 → 只剩秀兰农场的（山茶油 + A + B）。
6. 关键字输「测试视频B」→ 精确命中 1 条。
7. 点任意一行封面（或「预览」）→ 弹窗播放视频 + 标题 / 商家 / 简介 / 时长 / 审核意见 → 关闭。

### 5.2 驳回 B

8. 在「测试视频B」行点「审核」→ 弹窗：视频标题、商家、店铺、提交时间；审核结果默认「通过」。
9. 选「驳回」、意见留空 → 点「提交审核」→ 提示「驳回时请填写审核意见」，不提交。
10. 意见填「画面与助农主题无关，请补充产地与制作过程」→ 提交。
    - **该看到**：toast「已驳回」；该行审核状态变红「已驳回」，展示状态「未展示」。

### 5.3 商家侧核对驳回

11. 切到 farmer02 →「我的短视频」→ 筛选「已驳回」→ 看到「测试视频B」，卡片红色「已驳回」，下方显示 **「驳回原因：画面与助农主题无关…」**。
12. 切到商家工作台 →「视频被驳回」数字 +1。

### 5.4 通过 A

13. 管理端「测试视频A」行点「审核」→ 选「通过」，意见「内容合规，通过」（选填）→ 提交。
    - **该看到**：toast「已通过，视频将在前台展示」；状态变绿「已通过」，展示状态「展示中」。
14. 前台刷新 `#/videos` →「推荐」第一条就是「测试视频A-秀兰农场」，能正常播放。
15. farmer02「我的短视频」→ 视频 A 标签变绿「已通过」；工作台「视频审核中」-1。

### 5.5 复审（改判 + 下架/恢复）

16. 管理端筛选「已通过」，找到视频 A → 点「复审」→ 选「驳回」+ 原因「复审测试：临时下架」→ 提交。
    - **该看到**：toast「已驳回」；展示状态「未展示」。
17. 前台刷新 → 视频 A **消失**，掉出信息流。
18. 再「复审」→ 选「通过」→ 前台又出现，且发布时间**仍是第一次通过的时间**（不会变成现在）。

- [ ] 管理员审核通过

## 6. 第五轮：删除与越权（5 分钟）

### 6.1 删除已通过的视频

1. farmer02「我的短视频」→ 视频 A 卡片右下角「删除」→ 确认框「删除后买家将无法再看到这条视频，确认删除？」→「删除」。
2. toast「已删除」，卡片消失；前台刷新 → 视频 A 仍然看不到。
3. 再点一次删除？卡片已经没了。刷新页面 → 不会回来（逻辑删除）。

### 6.2 越权与权限对照

| # | 操作 | 预期 |
|---|---|---|
| 1 | 未登录直接访问 `#/merchant/videos` | 跳登录页，登录后回到该页 |
| 2 | buyer01 访问 `#/merchant/videos` | 黄色提示「该页面仅对农户商家开放」，回首页 |
| 3 | buyer01 在短视频页找「发布」 | 没有（只有 FARMER 显示） |
| 4 | buyer01 登录 3000 管理后台 | 能进后台也没有「短视频审核」菜单（该菜单只给 `video:audit`） |
| 5 | farmer01 前台刷信息流 | 看不到 farmer02 的待审核视频 |

## 10. 六个容易卡住的点

1. **找不到「发布」**：只有商家账号才有；而且它只跳到「我的短视频」页，还要再点一次「发布短视频」才弹窗。
2. **视频没声音**：浏览器拦截带声自动播放。点右上「点击开启声音」气泡，或点一下页面任意处。
3. **点了心形跳走了**：没登录。提示「登录后才能点赞、评论和关注」并跳登录，登录后自动回 `/videos`。
4. **关注 + 号不出现**：buyer01 三个商家都关注过了，先去商家主页点「已关注」取消，才会有 + 号。
5. **前台看不到刚发的视频**：正常。待审核不对外，必须管理员通过。
6. **赞数对不上明细**：种子里的赞/评是展示值，不等于明细表条数（米粉 128 赞但明细只有几条），只验 ±1，别拿明细去核对总数。
